# Received-part records

Add one ruler photograph, one caliper sketch, and one completed measurement row for every purchased part before final Fusion features are frozen.

Use filenames beginning with the BOM ID, for example:

- `PH-PROBE-01_label.jpg`
- `PH-PROBE-01_thread-caliper.jpg`
- `PH-PROBE-01_dimension-sketch.pdf`

Do not overwrite the planning values in the source documents without retaining the received-part evidence here.
